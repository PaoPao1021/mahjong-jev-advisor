# Steam 版使用指南（实验性）

适用：[Steam 雀魂客户端](https://store.steampowered.com/app/1329410/MahjongSoul/)。使用屏幕截图、模板匹配与 OCR，再调用 Jev 建议引擎。**不安装浏览器扩展，也不读取客户端内存。**

当前支持四人布局的实验性连续截图识别；三人局支持手动录入，每次局面变化后需要重新核对。尚未完成真实 Steam 对局验收，截图效果依赖你的分辨率、布局和样本，不能保证开箱即用。

## 下载与启动

在项目 [Releases](https://github.com/PaoPao1021/mahjong-jev-advisor/releases) 选择名称包含 `steam` 的 ZIP：

| 设备 | 文件后缀 | 启动程序 |
| --- | --- | --- |
| 64 位 Windows（Intel / AMD） | `steam-windows-x64.zip` | `MahjongJevAdvisor-Steam.exe` |
| Apple Silicon Mac | `steam-macos-arm64.zip` | `MahjongJevAdvisor-Steam.app` |

完整解压后启动，无需安装 Python。源码方式：Windows 双击 `run_steam_windows.cmd`；macOS 双击 `run_steam_macos.command`，或在项目目录执行 `zsh run_steam_macos.command`。源码首次启动需要 Python 3.12。

## Windows：绑定窗口

1. 运行 Steam 雀魂并进入四人牌局，保持窗口化、可见、无遮挡。
2. 启动 Steam 版顾问，打开【Jev设置】，填写服务商对应的 Key 并测试连接。
3. 【桌】→【绑定 Steam 雀魂窗口（Windows）】，选择游戏窗口。只采集客户区，移动窗口后自动跟踪；没有找到窗口时使用【选择牌桌画面】手动框选。
4. 点击【开始识别】，按提示核对手牌并学习牌面。自动定位失败时，用【桌】→【基础区域校准】分别框选手牌、摸牌及按钮，然后再核对。
5. 通过【扩展区域校准】补充牌河、宝牌、点数等区域；遇到未覆盖的牌，使用【标注牌面样本】或手动核对继续学习。
6. 对照游戏检查手牌和可见操作后使用建议。局风、自风、副露等信息可能不完整，识别不准时暂停并手动修正。

## macOS：手动框选

1. 启动游戏及 Steam 版顾问，为应用（源码启动时为对应终端）授权系统屏幕录制权限。
2. 完成【Jev设置】后，在【桌】→【选择牌桌画面】框选完整游戏画面。
3. 按上述校准、核对和学习流程开始识别。

macOS 暂无自动窗口绑定；手动框选后移动游戏窗口，需要重新框选。不要套用 Windows 自动跟踪的操作预期。

## 三人局：手动使用

【手动核对】→【玩法】→【三人麻将（雀魂）】，填写手牌、宝牌指示牌、实际可见按钮和局况，再请求建议。支持切牌、碰杠、和牌、拔北等候选；不提供吃牌。牌码中 `m/p/s/z` 为万 / 筒 / 索 / 字，字牌 1–7 是东南西北白发中，`0p/0s` 为赤五。

三人手动输入不会启动四人布局截图识别。每次摸打或其他操作后需要重新录入当前局面；如需三人连续自动识别，请使用网页版 Hook。

## 窗口变化和识别失败

- 绑定窗口最小化或关闭：清除当前局面与建议；恢复可见后重新采集，重启游戏需重新绑定。
- 绑定窗口改变大小：停止识别，重新校准。绑定只在本次顾问运行有效。
- 手动框选后移动窗口：重新选择牌桌画面。重新框选或绑定会清除当前模式的区域校准。
- 显示待核对：检查手牌样本、区域、缩放和皮肤，必要时暂停并手动输入。
- 关闭覆盖牌桌的其他窗口和 Steam 浮层。此路径不支持后台或最小化采集，也无法识别所有遮挡；全屏、混合 DPI、动画仍需实机验证。
- 短暂网络失败会有限次数自动重试；此机制不能修复错误的牌面识别。

## 与网页版并存

Steam 版使用 `%APPDATA%\mahjong-jev-advisor-steam`（Windows）或 `~/Library/Application Support/mahjong-jev-advisor-steam`（macOS）；不会覆盖网页版配置。模型 Key 需要单独填写；模板、区域与日志也分开保存。不同版本解压到不同文件夹即可并存，无需卸载旧版。

官网：[TypeSafe](https://typesafe.ai/)、[Vercel AI Gateway](https://vercel.com/ai-gateway)、[OpenRouter](https://openrouter.ai/)。Key 不通用，模型服务可能收费。截图不直接发送给 Jev，识别出的手牌、公开局况和候选动作会发送给配置的在线服务。

启动包未商业签名或 Apple 公证；遇到系统拦截，请先核对来源及 SHA256，再使用系统提供的放行选项。勿分享包含明文 Key 的本机配置。
