雀魂 · Jev 实时决策顾问 — 快速开始

1. 将整个 ZIP 解压到固定文件夹。不要在压缩包里启动，也不要单独移动 EXE。
   Windows：双击 MahjongJevAdvisor.exe。
   macOS：双击 MahjongJevAdvisor.app，并保留同目录 browser-extension 文件夹。
   不需要安装 Python、pip 或额外下载 OCR 模型。

2. 点击【Jev设置】，选择平台，填写自己的 API Key，测试连接成功后保存。
   官网：TypeSafe https://typesafe.ai/
         Vercel https://vercel.com/ai-gateway
         OpenRouter https://openrouter.ai/
   各平台 Key 不通用。在线服务可能收费，软件包不包含 Key 或额度。
   【大模型设置】仅用于可选的【深度解析】。

3. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
   开启开发者模式，加载本包中的 browser-extension 文件夹。
   桌面程序【桌】→【打开网页 Hook 扩展目录】也能定位此文件夹。
   完整刷新雀魂网页，再进入牌局；看到“实时牌局已识别”后核对手牌。
   若尚未自动运行，点击【开始识别】。

4. 三人/四人玩法由 Hook 自动识别。你仍需自行在游戏中执行操作。
   Hook 模式不要求截图校准；截图备用模式需要录屏权限、区域校准及模板。

Steam 客户端（实验性，四人截图布局）：
  【桌】→【输入来源】→【Steam 客户端（截图）】。
  Windows 可用【绑定 Steam 雀魂窗口（Windows）】；macOS 请【选择牌桌画面】。
  保持游戏窗口化、可见且无遮挡，再【开始识别】，按提示校准并核对 / 学习手牌。
  自动定位失败时使用【基础区域校准】；按需补充扩展区域与牌面样本。
  手动框选后移动窗口需重新框选；绑定窗口缩放后需重新校准。
  浏览器和 Steam 的校准、模板互相独立，模型 Key 共用。
  Steam 不需要浏览器扩展；三人局每次局面变化后需手动录入，不能连续截图识别。
  此路径尚未完成真实 Steam 对局验收，请核对识别结果，详见 README。

本候选包未使用商业证书签名，也未完成 Apple 公证。
Windows SmartScreen 或 macOS Gatekeeper 可能提示来源未知。
请先确认下载来自项目仓库并核对 SHA256，再通过系统提供的“仍要运行”/
“隐私与安全性 → 仍要打开”选项授权；不要关闭全局系统防护。
如果系统没有提供放行选项，可按 README 使用源码启动。

配置保存在用户目录，升级时替换程序即可；扩展更新后需重新加载并刷新游戏。
API Key 在本机 settings.json 中明文保存，不要分享该文件。
在线分析会将自己的手牌和公开局况发送到所选服务。
